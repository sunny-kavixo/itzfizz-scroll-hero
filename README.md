# Itzfizz Scroll-Driven Hero

A premium scroll-driven hero experience created for the **Itzfizz Digital Web Development Internship assessment**.

## What this demonstrates
- Initial staggered headline and metric reveals
- GSAP ScrollTrigger pinned, scrubbed animation
- Scroll-progress-driven scene, device and content movement
- Transform/opacity-first animation for performance
- Responsive layout and reduced-motion support
- React + Next.js + Tailwind CSS + GSAP

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```
